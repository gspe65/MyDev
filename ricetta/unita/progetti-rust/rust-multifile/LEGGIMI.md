# multifile — Un programma su due file

**Compilatore:** `cargo`

La versione Rust di `progetti/multifile`. Il `Makefile` del C elenca a mano quali file compilare e in che ordine: `cargo` lo ricava da solo seguendo le righe `mod`.

## Comandi

```bash
cargo run
```
