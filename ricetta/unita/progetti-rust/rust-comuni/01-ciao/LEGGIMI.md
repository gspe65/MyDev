# 01 — Ciao mondo

**Compilatore:** `cargo`

Stampa una riga ed esce. Se questo funziona, l'ambiente e' a posto.

## Comandi

```bash
cargo run
```

## Cosa devi vedere

```
Ciao, mondo!
```

## Dove sta l'`unsafe`

Nessuno: qui non serve.

## Prova tu

Fai stampare anche il tuo nome, su una seconda riga.
Poi cambia `println!` in `print!` e guarda cosa cambia.
